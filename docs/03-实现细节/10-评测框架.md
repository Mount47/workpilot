## Eval Suite

JSON Suite 包含名称、版本和案例。每个 EvalCase 包含：

- case_id；
- workspace；
- goal；
- expected_evidence_quotes；
- expected_status；
- bad_case_ids：关联已经登记的真实异常。

相对 workspace 路径以 Suite 文件所在目录解析。

## 执行隔离

每个案例创建独立 Runtime 和输出目录。单案例 workspace 无效或运行异常时记录 `evaluation_error`，不会阻止后续案例。

## 当前指标

- Task Completion Rate；
- Evidence Precision / Recall；
- Citation Validity Rate；
- Claim Support Rate；
- Unsupported Claim Rate；
- Revision Recovery Rate；
- Average Revision Count；
- Semantic Unverified Count。

证据质量门禁接入后新增：

- Source Coverage Rate；
- Evidence Acceptance Rate；
- Evidence Discard Rate；
- Average Locator Repair Count；
- Claim Source Coverage Rate；
- Evidence Repair Trigger Rate；
- Evidence Repair Recovery Rate；
- Average Repair Model Call Count；
- Average Repair Token Count；
- Average Repair Estimated Cost。

Repair 调用和 Token 只统计 `evidence_repair_requested` 到下一次 `evidence_quality_evaluated` 之间的物理模型调用，不会把后续 Claim 生成和业务修订错误计入修复成本。Provider 未返回价格时成本保持 `null`。

Citation Validity、Claim Support、Unsupported Claim 和 Claim Source Coverage 使用可空语义。Case 没有执行对应检查时输出 `null`，CLI 显示 `N/A`；Suite 宏平均忽略 N/A，避免将零检查误判为 100%。该修复来自 BC-003。

## 使用方式

```bash
workpilot eval \
  --suite evals/最小基线.json \
  --provider stub \
  --output runs/eval-baseline
```

输出目录包含总体 `eval_report.json` 和每个案例的完整 Run Artifact。

真实模型 Bad Case 回归使用独立 Suite，避免复用 Stub 基线名称：

```bash
workpilot eval \
  --suite evals/BC-001真实回归.json \
  --provider qwen \
  --model qwen-plus \
  --output runs/qwen-plus-bc001-regression-next
```

## Planner 离线评测

PlannerEvalRunner 使用静态 Provider 重放 PlanDraft 或稳定 Provider 错误，但实际执行 ConstrainedLLMPlanner、PlanValidator、RuntimePlanPolicy 和 FallbackPlanner，不绕过生产控制逻辑。

当前指标：

- Decision Accuracy；
- Plan Validity Rate；
- LLM Acceptance Rate；
- Fallback Rate；
- Failure Rate；
- Unsafe Acceptance Rate；
- Average Input/Output Tokens；
- Average Latency。

```bash
workpilot planner-eval \
  --suite evals/Planner最小基线.json \
  --output runs/planner-eval-baseline
```

输出 `planner_eval_report.json`，不保存 Prompt 或模型响应正文。

当前五个案例结果：Decision Accuracy 100%、Plan Validity 80%、Fallback 60%、Unsafe Acceptance 0%。认证失败按预期不返回计划，因此 Plan Validity 不是 100%。这些数据只证明控制逻辑按标注执行，不能代表真实模型质量。

## 当前基线边界

业务报告评测当前只有一个人工固化 Case；Planner 评测当前只有五个离线控制案例。BC-001 已使用 qwen-plus 真实复跑：门禁正确触发且 Run fail closed，但 Repair Recovery 为 0%，形成 BC-002。下一步需要改进定向修复，并扩展多文件、冲突、证据不足、错误引用和修订恢复样本。
