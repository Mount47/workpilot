# 评测框架实现

## 对应代码

- `src/workpilot/evaluation/models.py`
- `src/workpilot/evaluation/runner.py`
- `src/workpilot/cli.py`
- `evals/最小基线.json`

## Eval Suite

JSON Suite 包含名称、版本和案例。每个 EvalCase 包含：

- case_id；
- workspace；
- goal；
- expected_evidence_quotes；
- expected_status。

相对 workspace 路径以 Suite 文件所在目录解析。

## 执行隔离

每个案例创建独立 Runtime 和输出目录。单案例 workspace 无效或运行异常时记录 `evaluation_error`，不会阻止后续案例。

## 当前指标

- Task Completion Rate；
- Evidence Precision / Recall；
- Citation Validity Rate；
- Claim Support Rate；
- Unsupported Claim Rate；
- Revision Recovery Rate；
- Average Revision Count；
- Semantic Unverified Count。

## 使用方式

```bash
workpilot eval \
  --suite evals/最小基线.json \
  --provider stub \
  --output runs/eval-baseline
```

输出目录包含总体 `eval_report.json` 和每个案例的完整 Run Artifact。

## 当前基线边界

当前只有一个根据 Stub 行为人工固化的回归案例。100% 指标仅证明确定性链路和指标计算可以重复运行，不能证明真实模型或复杂企业项目场景达到 100%。下一步需要独立人工标注多文件、冲突、证据不足、错误引用和修订恢复案例。
