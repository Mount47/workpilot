# 工作区工具实现

## 对应代码

- `src/workpilot/workspace/tools.py`

## 当前接口

- `list_files()`：递归列出文件并返回相对路径；
- `read_file(relative_path)`：读取 UTF-8 文本；
- `search_text(keyword)`：大小写不敏感地搜索行文本。

## 安全边界

所有相对路径都经过 `_resolve_safe()` 解析，并检查解析结果仍位于 workspace root 中。路径越界会抛出 `PermissionError`。

## 当前限制

- 使用字符串前缀判断路径边界，后续应改为更严格的 `Path.is_relative_to()`；
- 没有忽略文件规则和符号链接策略说明；
- 没有文件大小、文件数量和总读取量限制；
- 只按 UTF-8 文本读取；
- 不理解 Markdown、CSV 等结构语义；
- 搜索会重复扫描全部文件；
- Runtime 已由 PlanExecutor 按 Tool Registry 中的工具名受控分派，但尚未形成统一 Tool Handler/ToolResult 协议，Contract 的工具白名单也未全面接入。

## 后续迁移

WorkspaceTools 应保留为底层工具，其输出逐步转换为 SourceDocument 与 ContentUnit；后续再以统一 Tool Handler/ToolResult 替换 Runtime 中按名称分派的过渡实现。
