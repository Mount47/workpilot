## 配置与发现

- ✅ Settings 统一 API Key 映射；
- ✅ `.env.example` 覆盖全部内置 Provider；
- ✅ `workpilot providers` 展示 transport、默认模型和结构化能力；
- ✅ Custom 强制 model 和 base_url；
- ✅ 版本化 JSON Route Config 和不含密钥的档位示例；
- ✅ CLI `--route-config` 接入 Runtime；
- ✅ Provider Key 严格按厂商环境变量隔离；
- ✅ 缺 Key 在 SDK Client 创建前 fail closed；
- ✅ `workpilot doctor` 单 Provider 和 Route Config 离线预检；
- ✅ Base URL 凭据、查询参数和非本地 HTTP 安全检查；
- ✅ Doctor 与配置错误不输出真实 Key；
- ⬜ Provider-specific 参数白名单；
- 🚧 显式模型 Failover 已完成，多 Endpoint 负载均衡待实现。
