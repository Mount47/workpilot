# 基础运行时开发计划

## 状态机与运行生命周期

- ✅ 定义 Run 与 RunState；
- ✅ 支持 pending、planning、retrieving、synthesizing、verifying、revising、passed、failed、cancelled 状态；
- ✅ 终态后禁止继续迁移；
- ✅ 记录运行开始和结束时间；
- 🚧 固定流程能够端到端运行，但状态迁移规则仍较宽松；
- ⬜ 建立显式状态迁移表；
- ⬜ 持久化 Run 状态；
- ⬜ 支持安全取消；
- ⬜ 支持检查点恢复。

## Mission Contract

- ✅ 定义目标、工作区、允许工具、最大步骤、Token 和时间预算；
- ✅ 规范化 workspace 路径；
- 🚧 提供工具和 Artifact 判断方法；
- ✅ 六个高层计划工具已检查 Registry、Contract 和输入 Schema，并通过统一 Tool Handler 执行；
- ✅ Runtime 强制执行最大步骤数；
- ✅ Runtime 强制执行时间预算；
- ✅ Runtime 强制执行 Token 预算；
- ⬜ 保存 Contract 快照并写入输出目录。

## 执行与失败处理

- ✅ 顶层异常转为 failed 并写入 Trace；
- ✅ 预算耗尽转为明确失败且保留预算摘要；
- ✅ 引用验证错误经过最多三次生成/修订后失败关闭；
- 🚧 修订反馈包含具体错误，但仍重新生成整组 Artifact；
- ⬜ 标准错误码和错误分类；
- ⬜ 按错误类型定向修订；
- ⬜ 工具超时、退避和可重试性策略；
- ⬜ 幂等键与重复执行保护。

## CLI 与 API

- ✅ `workpilot run` 基本命令；
- ✅ `workpilot trace` 基本查看；
- 🚧 `workpilot verify` 命令存在但尚未实现；
- ✅ `workpilot eval` 与 `workpilot planner-eval`；
- ✅ 查询运行状态、报告、Evidence、验证结果和源文件的 HTTP API；
- 🚧 Run 列表 API 已实现，但注册表为内存态，服务重启后无法恢复历史；
- ⬜ 取消和恢复运行接口。
