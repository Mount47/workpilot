# 企业数据连接器开发计划

## 连接器基础

- 🚧 本地 UTF-8 文本 workspace 可作为最初文档连接器；
- ⬜ Connector 接口；
- ⬜ SourceDocument / ContentUnit 输出协议；
- ⬜ 来源身份、版本、Hash 和更新时间；
- ⬜ 连接器权限与凭证接口；
- ⬜ 增量同步和删除处理。

## 第一批连接器

### Markdown 与文本

- ✅ 基础文件读取；
- 🚧 行级定位可用，缺少标题层级和元数据解析；
- ⬜ 文件大小限制、编码识别和忽略规则。

### Excel 与 CSV

- 🚧 CSV 会被当作普通文本读取，没有表格语义；
- ⬜ Workbook/Sheet/Range 定位；
- ⬜ 表头和数据类型识别；
- ⬜ 任务、里程碑和风险表标准化；
- ⬜ 公式值与原始值策略。

### PDF 与 Word

- ⬜ 页码、段落和表格解析；
- ⬜ 扫描 PDF 与 OCR 降级；
- ⬜ 页面/段落 Locator；
- ⬜ 解析质量和丢失内容检测。

## 后续连接器

- ⬜ 会议转写；
- ⬜ 邮件；
- ⬜ Jira、飞书项目、TAPD、Asana 或 Notion 中至少一种；
- ⬜ 数据库只读查询；
- ⛔ Git/PR/CI 不作为通用企业项目主线，仅在研发垂直版本中评估。

## 验收要求

每个连接器必须提供脱敏 fixture、定位验证、权限测试、错误输入测试和端到端评测对比。不能仅证明“文件可以打开”。
