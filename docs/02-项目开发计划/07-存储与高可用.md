# 存储与高可用开发计划

## 持久化

- 🚧 Artifact 和 Trace 写入本地文件；
- 🚧 Evidence 仅在内存中保存；
- ⬜ SQLite 数据模型和迁移；
- ⬜ Project、Run、Plan、Evidence、Claim、Memory、Verification 持久化；
- ⬜ Repository 接口隔离具体数据库；
- ⬜ 文件 Artifact 与数据库索引一致性；
- ⬜ 事务边界和失败回滚。

## 恢复与幂等

- ⬜ Run 检查点；
- ⬜ Step 幂等键；
- ⬜ Tool Call 去重；
- ⬜ Provider 调用重试策略；
- ⬜ 进程退出后恢复；
- ⬜ 部分 Artifact 清理与恢复；
- ⬜ 重复任务检测。

## 并发与可用性

- ⬜ 项目级并发限制；
- ⬜ 数据库乐观锁或租约；
- ⬜ 后台任务队列；
- ⬜ 限流与背压；
- ⬜ 健康检查；
- ⬜ 服务级指标和告警；
- ⬜ 多实例失败接管。

## 工程交付

- ⬜ lint 和 type check；
- ⬜ CI 中运行 unit、integration 和 small eval；
- ⬜ Docker 一键运行；
- ⬜ 示例企业项目 workspace；
- ⬜ 配置、密钥和环境说明；
- ⬜ 备份与数据迁移说明。
