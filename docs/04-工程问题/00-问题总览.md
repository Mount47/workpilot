## 问题分类

| 类别 | 典型问题 | 当前状态 |
|---|---|---|
| 模型与结构化输出 | JSON 无法解析、字段缺失、Provider 差异 | 🚧 已有基础重试和降级 |
| Evidence 与验证 | quote 漂移、行号失效、引用不支持结论 | 🚧 引用真实性已部分处理 |
| Memory | 过期、污染、跨项目泄露、错误覆盖 | 🚧 Run 级 Working Memory 已实现，长期记忆待实现 |
| Planner 与工具 | 非法工具、循环计划、预算失控、参数错误 | 🚧 确定性 Planner、Registry 和校验器已实现 |
| 数据连接器 | 编码、扫描 PDF、Excel 合并单元格、增量同步 | 🚧 仅文本基础能力 |
| 并发与恢复 | 重复执行、部分写入、恢复后再次调用外部工具 | ⬜ 尚未实现 |
| 安全与隔离 | 路径越界、Prompt Injection、日志泄密 | 🚧 路径保护已实现 |
| 评测 | 标注不一致、指标失真、真实模型不可复现 | 🚧 最小 Stub Eval 已实现，真实数据集待扩充 |
| 成本与性能 | 长文档、过多模型调用、延迟抖动 | 🚧 Token、步骤和耗时预算已实现，真实成本待量化 |
